# 프로필 사진

About 페이지 상단에 들어가는 사진입니다.

## 넣는 법

1. 이 폴더에 사진을 넣습니다. 예: `jiwoo.jpg`
2. `src/data/about.ts` 의 `profileImage` 에 경로를 씁니다.

```ts
export const profileImage = "/profile/jiwoo.jpg";
```

비어 있으면 회색 플레이스홀더가 대신 표시되며, 레이아웃은 그대로 유지됩니다.

## 사진 조건

| 항목 | 권장 |
|---|---|
| 비율 | **세로 4:5** (예: 1200 × 1500px) |
| 크롭 | `object-cover`로 잘리므로 **인물이 가운데** 오도록 |
| 용량 | 500KB 이하. `next/image`가 자동으로 최적화하고 WebP로 변환합니다 |
| 형식 | JPG 또는 PNG |

4:5가 아닌 사진을 넣어도 알아서 잘리지만, 의도한 구도가 잘릴 수 있으니
미리 4:5로 잘라서 넣는 편이 안전합니다.

## 대체 텍스트

스크린리더가 읽는 설명은 `src/data/about.ts` 의 `profileAlt` 에 있습니다.
사진을 바꿔도 대부분 그대로 두면 됩니다.

**썸네일과 상세 이미지는 다른 그림을 쓴다.**

## 세로로 긴 이미지는 가로 2048px을 넘기지 말 것

WebP는 한 변이 **16383px**을 넘을 수 없다. 이 케이스 스터디 이미지는
세로가 가로의 6.3배라, 가로 2599px을 넘으면 세로가 한계를 넘어
**WebP 인코딩이 실패하고 원본 PNG가 그대로 방문자에게 전송된다.**
3840px을 요청하면 14MB PNG가 내려간다.

Next.js의 기본 폭 단계는 640 / 750 / 828 / 1080 / 1200 / 1920 / 2048 / 3840이므로,
실질적인 상한은 **2048px**이다. 원본을 그보다 크게 넣어도 화질 이득이 없고
위험만 생긴다.

현재 원본: **1920 × 12100**

## 화질

`quality={90}`을 쓴다. 기본값 75는 작은 글씨 가장자리에 압축 잡티를 남긴다.
Next 16부터는 `next.config.ts` 의 `images.qualities` 에 값을 등록해야 한다.

실측 (1200px 폭 기준, WebP):

| 품질 | 용량 |
|---|---|
| 75 | 349 KB |
| **90** | **568 KB** |
